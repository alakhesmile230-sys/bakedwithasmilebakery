1. Project Overview
Baked with a Smile Bakery is a fictional bakery that provides high-quality baked goods using fresh ingredients, traditional baking techniques and excellent customer service. Although the business primarily serves customers through its physical stores, it aims to expand its online presence through a professional website that is informative, visually appealing and easy to navigate.

The Baked with a Smile Bakery Website Project focuses on planning, designing and developing a professional website that provides customers with convenient access to information about the bakery, its products, services and contact details. The website aims to improve the bakery’s online visibility, strengthen customer communication and create a positive online experience (Chaffey and Ellis-Chadwick, 2022).

1.1 Mission Statement
To provide freshly baked, high-quality products that bring happiness to every customer while delivering exceptional service and creating memorable experiences for every occasion.

1.2 Vision Statement
To become one of South Africa’s most recognised neighbourhood bakeries by combining traditional baking with modern technology and outstanding customer service.

2. Website Goals and Objectives
2.1 Website Goal
The primary goal of the Baked with a Smile Bakery website is to establish a professional online presence that allows customers to access information about the bakery, its products, services, locations and contact details.

The website also aims to increase customer engagement and generate enquiries through an accessible and user-friendly online platform.

Accessibility is an important consideration because websites should allow people with different abilities to perceive, understand, navigate and interact with online content (W3C, 2024).

2.2 Website Objectives
The website aims to achieve the following objectives:

Increase online visibility: Establish a professional online presence that allows potential customers to discover and learn about Baked with a Smile Bakery.
Promote products and services: Display the bakery’s cakes, cupcakes, bread, pastries, cookies, custom cakes and catering services.
Generate customer enquiries: Provide online enquiry forms that allow customers to request information about custom cakes, catering and other bakery services.
Improve customer communication: Provide contact information, operating hours and location details to help customers communicate with and visit the bakery.
Improve user experience: Use clear navigation, organised page layouts, readable content and consistent design.
Improve accessibility: Include appropriate headings, descriptive links, alternative text for images, readable content and accessible forms.
Improve website functionality: Introduce JavaScript features that make the website more interactive and convenient to use.
Improve search engine visibility: Apply SEO techniques such as descriptive page titles, meta descriptions, relevant keywords and image alternative text.
These objectives support usability, accessibility and the creation of helpful website content (Google, 2025; W3C, 2024).

2.3 Website Success Metrics and KPIs
The success of the website will be evaluated using the following Key Performance Indicators (KPIs):

Number of website visitors.
Number of completed online enquiries.
Number of custom cake enquiries.
Number of catering enquiries.
Number of visitors viewing the Products page.
Number of visitors using the Contact page.
Website usability and accessibility testing results.
Website performance across desktop, tablet and mobile devices.
These measurements will help evaluate whether the website is achieving its intended objectives.
